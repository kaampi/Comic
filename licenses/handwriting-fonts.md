# Handwriting font notices

kaampi Comic bundles local webfont files for these Google Fonts families:

- Patrick Hand — SIL Open Font License 1.1
- Handlee — SIL Open Font License 1.1
- Bad Script — SIL Open Font License 1.1
- Gochi Hand — SIL Open Font License 1.1
- Rancho — Apache License 2.0

The local WOFF files are packaged from the Fontsource Google-font collection for offline use.
Upstream family metadata and licensing originate from the Google Fonts repositories.

These five bundled handwriting fonts are loaded locally and require no network access at runtime.
